# Money Saathi

Money Saathi is a mobile-first personal finance dashboard for tracking spending, budgets, recurring payments, and financial insights.

## Stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Neon-backed project configuration

## Development

Install dependencies with pnpm, then run the Next.js development server with `pnpm dev`.

## Deployment

The project is designed to remain connected to its existing Vercel/v0 deployment. Keep secrets in Vercel environment variables; do not commit `.env` files or credentials.
